# Health Records Manager

A personal health management application built with React, TypeScript, Vite, Bootstrap, and Firebase.

## Features

- Personal health dashboard
- Medical records management
- Medication tracking
- Appointment management
- Responsive dark-themed UI
- Firebase Authentication
- Firestore database integration
- Secure, user-specific health records

## Tech Stack

- React
- TypeScript
- Vite
- Bootstrap
- Firebase Authentication
- Cloud Firestore


## Project Status

Currently in development. The dashboard UI is being built, with Firebase integration, authentication, medical record management, and security rules planned for implementation.
